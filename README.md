# PROJECT LOCKSTEP

**Current product:** Native iOS real-time deterministic tactical combat  
**Native build:** `iOSNative/`  
**Status:** v0.1.0 prototype in active development

The previous VECTOR GRID web prototype has been retired as the game concept. Its files remain temporarily in the repository only as legacy material while the native replacement stabilizes.

## Core rule

Competitive gameplay contains no RNG. Damage, movement, cooldowns, projectile speed, energy, target selection, and objective progress are deterministic.

## Current direction

PROJECT LOCKSTEP is a native iPhone game built with Swift, SpriteKit, and SwiftUI. You directly control a Commander in real time while issuing quick movement commands to three combat drones. The opponent follows the same underlying combat rules and the development AI uses deterministic priorities.

See [`iOSNative/README.md`](iOSNative/README.md) for the current gameplay specification and native build instructions.
